# IEEE project reports

- [Phase I prototype report](phase-i.pdf) covers the design and the six-read Verilog demo.
- [Phase II evaluation report](phase-ii.pdf) covers all seven workloads, verification, and synthesis.

The editable sources are `phase-i.tex` and `phase-ii.tex`. Update
`authors.tex` and the Individual Contributions section in each report
with the team's confirmed details before submission.

From this directory, rebuild both IEEEtran PDFs with Tectonic:

```sh
tectonic phase-i.tex
tectonic phase-ii.tex
```
